## 评估框架

对每个新工具，按以下维度评估：

### 1. 重叠分析
- 现有工具是否已覆盖该工具的核心能力？
- 现有工具的覆盖深度是否更强？

### 2. 互补分析
- 该工具是否覆盖现有体系缺失的能力？
- 缺失部分能否用现有工具平替？

### 3. 成本分析
- 免费额度 vs 付费订阅
- 安装和维护成本

### 4. 结论
- 安装 / 不安装 / 有条件安装
- 明确理由

## 已评估项目

### AgentKey（2026-07-22 结论：不安装）

**本质：** 付费订阅的统一 MCP 网关（Lite/Pro/Max 三档），一个 Key 接入 28+ 平台。

**收费：** 月费 + 积分超量计费，有免费试用但不是永久免费。

**对比：**
| 能力 | 现有 | AgentKey | 结论 |
|:-----|:-----|:---------|:-----|
| 网页搜索 | open-webSearch+Tavily+Exa+AnySearch | Tavily+Serper+Brave+Perplexity | ✅ 更强 |
| 知乎 | zhihu-search（站内+直答+热榜） | 知乎数据 | ✅ 更强 |
| 小红书 | xhs-cli（完整客户端） | 小红书数据 | ✅ 更强 |
| 微博/B站/抖音/微信 | ❌ | ✅ | 🔄 可平替 |
| 热点 | TrendRadar（8平台） | ❌ | ✅ 更强 |

**不安装原因：** 重叠部分更强，缺失部分可平替，付费不划算。

---

### Codex Skill Universe（2026-07-22 结论：不安装）

**本质：** 本地 Web 应用（3D Skill 管理仪表盘），不是 API 服务。

**四种形态：**
| 形态 | 能被 Agent 调用？ |
|:----:|:------------------:|
| Skill | ✅ 可以 |
| API（REST） | ⚠️ 仅本地跑 dev server 时 |
| MCP | ❌ |
| CLI | ❌ |

**不安装原因：** 只给人用，不给 Agent 用。Agent 推荐 Skill 用 find-skills + skills.sh。
