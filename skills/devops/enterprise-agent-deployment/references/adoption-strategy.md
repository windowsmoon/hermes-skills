# 先做后说 — 企业 Agent 部署的政治策略

> 核心原则：不提案，用结果说话。

## 问题背景

你在组织内推动 Agent 基础设施时遇到的典型阻力：

| 角色 | 使用的 Agent | 阻碍原因 | 本质 |
|------|-------------|---------|------|
| 发哥 | Hermes | 不表态支持 | 没看到"建服务器"对他有什么好处 |
| 阿展 | Codex | 明确反对 | 担心权限不可控，数据混在一起 |

## 为什么不能直接提案

不是方案不好，是你的角色在组织里不是"决定 Agent 战略的人"。连续两次提案失败说明：**这个事不是靠提案能推成的。**

### 关键红线

如果你已经连续两次提出过同类方案，且在对方没有明确支持的情况下：

> **绝对不要第三次提案。** 第三次提案不是"再试一次"，是"不识趣"。

对方已经知道你在这件事上的立场。再提一次只会让他们觉得你"不懂看脸色"、"固执"、"不听劝"。正确的做法是：**不提了，自己干。**

### 你的角色定位

你不是 CTO、不是技术 VP、不是 IT 部门负责人。你是猎头顾问 + AI 副业爱好者。在这个组织里，你的角色决定了方案不是由你来推的。能推的事情是"你能帮谁解决什么问题"，而不是"你应该怎么做"。

## 三阶段策略详解

### Phase 1：先做后说（1-2天）

**动作：**
1. 把自己的 Hermes 环境整理成可复用的模板（GLOBAL/ 目录）
2. 把你的 Skill 依赖整理成 SKILL_DEPENDENCIES.md
3. 把你的飞书多账号、GitHub 账号整理成对应 MD 文件
4. 跑通"从模板恢复环境"的流程
5. 写一份《Hermes 双人协作指南》——你跟发哥共享 GLOBAL 模板

**话术：**
> "发哥，我这边整理了一套 Agent 配置模板，换电脑不用重新配置了，你看看要不要也搞一份？"

这不是"提案"，是"分享经验"。发哥自己觉得有用，他会自己推。

**判别标准：** 发哥看到后说"这个不错"——不需要他主动采纳，只需要他认可价值。

### Phase 2：部门试点（1-3个月）

**触发条件：**
- 有人（运营/研发/人事）看到你用 Hermes 的效果，主动问"这个我能用吗？"
- 或者发哥自己开始整理他的 Hermes 环境

**动作：**
1. 用 init_department.py 创建部门 Profile
2. 部门主管设置 token 预算
3. 部门成员各自有独立 Profile，共享部门 Skill
4. 输出《部门 Agent 运营报告》——月度 token 用量、任务完成数、热门 Skill

**话术：**
> "你们部门要搞的话，需要确定一个主管来管 token 预算，我来帮你们搭。"

**关键原则：**
- 不是你主动推，是对方问"能不能帮我也搞一个"
- 把自己定位成"帮忙搭"而不是"主导推行"
- 部门隔离是卖点不是缺点——阿展反对的是"混在一起"，部门隔离正解决他的顾虑

### Phase 3：横向扩展（3-6个月）

**门槛：** 至少 2 个部门主动接入，有明确的 Token 成本分摊机制

**动作：**
1. 多部门注册到 DEPARTMENTS.md
2. 全局 Skill 市场（部门间共享已验证的 Skill）
3. 网关层（多实例负载均衡，可选）
4. 审计日志
5. 管理员培训

## 组织利益分析

### 对发哥（Hermes 用户，不表态）
- **他的利益：** Token 成本降低、Skill 复用、不用重复配置
- **你的策略：** 先做后说，让他看到结果
- **触发点：** "换电脑不用重新配置"

### 对阿展（Codex 用户，反对）
- **他的顾虑：** 权限不可控，Codex 数据混在 Hermes 环境里
- **你的策略：** 部门隔离，Profile 互不可见
- **触发点：** "部门隔离，你的 Codex 完全独立，跟 Hermes 不互通"

### 对业务部门主管
- **他们的利益：** 零门槛获得 Agent 能力，主管管预算
- **你的策略：** 等人来问，帮他们搭
- **触发点：** 看到你一天能干完他们一周的活

## 时间线建议

| 阶段 | 预计 | 条件 |
|------|------|------|
| Phase 1 | 1-2 天 | 只需要你一个人 |
| Phase 2 | 1-3 个月 | 等有人主动问 |
| Phase 3 | 3-6 个月 | 至少 2 个部门接入后 |

## 重要提醒

1. **不要跳过 Phase 1 直接推 Phase 2。** 在自己没跑通之前不要跟任何人说"我有个方案"。
2. **不要第三次提案。** 已经失败了两次，第三次只会让你更难堪。
3. **先做后说，用结果说话。** 没有比发哥自己说"这个不错"更有说服力的了。
