# 红框检测算法说明

## 原理

batch_annotate.py 使用 numpy 做像素级红色检测，不依赖 OpenCV。

## 检测条件

红色像素判定：`R > 180 AND G < 100 AND B < 100 AND (R - G) > 80`

## 检测流程

```
原始图像 → RGB 数组 → 红色掩码 → 行列投影 → 连续段分组 → 
XY 组合成候选框 → 红色密度验证（>5%）→ 重叠合并 → 排序输出
```

## 参数调优

如果用户画的红色方框检测不到，可能原因：
1. 红色不够纯（用户用了偏粉/偏橙的红色）→ 调低 R 阈值到 150
2. 框太细（1px）→ numpy 检测需要至少 2-3px 宽的线条
3. 背景也有大量红色像素 → 提高 R 阈值到 220

## 输出排序规则

检测到的红框按 (Y, X) 排序：先按 Y 轴（从上到下），Y 相同时按 X 轴（从左到右）。
这与"从上到下、从左到右匹配口播步骤"的约定一致。

## 不支持的框样式

- 虚线框（红色虚线像素不连续，无法形成完整矩形）
- 填充色块（用户画了红色填充方块，不是边框）
- 非矩形框（圆形、手绘不规则形状）
