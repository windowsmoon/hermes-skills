# 框架模板使用说明

## 两种模板

skill 提供了两种模板供你选择：

### A. Obsidian Markdown（推荐）
文件：`框架模板-Obsidian用.md`
用法：在 Obsidian 中打开，Ctrl+V 粘贴截图，填写标注要求。
**优点**：不需要自己写文件名，Obsidian 自动存图。

### B. HTML 拖拽版
文件：`框架模板-HTML版.html`
用法：浏览器打开，拖拽图片到框里，填写标注信息，导出配置。
**优点**：不需要 Obsidian，纯本地运行。

## 首次使用步骤

1. 把对应的模板文件**复制**到你的截图目录（不要直接在 skill 目录下操作）
2. 打开模板文件，按说明粘贴截图并填写信息
3. 把文件路径发给 Hermes Agent

## 模板可以复用

截图目录清理后，模板文件可以留着下次继续用。
