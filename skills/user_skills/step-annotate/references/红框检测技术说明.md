# 红框检测批注模式

## 原理

用户用 Snipaste / 微信截图 / 任何画图工具在截图上画 **红色方框**，
框出需要标注的目标区域。Agent 然后：

1. 用 `vision_analyze()` 快速确认画面内容
2. 用 `scripts/batch_annotate.py` 的 `detect_red_boxes()` 函数
   自动检测红色像素矩形
3. 根据口播稿步骤，在每个红框位置添加编号圆 + 箭头 + 说明文字
4. **不覆盖用户的红色方框**

## 为什么有效

- **用户控制位置**：用户精确圈出要标注的 UI 元素，零歧义
- **AI 控制文字**：Agent 从口播稿匹配步骤文字，不依赖用户手动写标注
- **支持一张图多个红框**：按从上到下、从左到右排序，匹配连续步骤
- **视觉互斥**：用户红框（目标指示）和 AI 编号圆/箭头（标注说明）不重叠

## 技术实现

### 红色检测算法

```python
def detect_red_boxes(img):
    arr = np.array(img.convert("RGB"))
    r, g, b = arr[:,:,0], arr[:,:,1], arr[:,:,2]
    red_mask = (r > 180) & (g < 100) & (b < 100) & (r - g > 80)
```

### 使用约束

- 框的线条建议 ≥ 2px，红色 R > 180
- 框不要互相重叠（算法会合并重叠框）
- 不兼容紫色/橙色框 —— 只识别纯红色

### 输出文件名

`步骤<编号>-<标注文字>.png`，多框时跨图连续编号。
