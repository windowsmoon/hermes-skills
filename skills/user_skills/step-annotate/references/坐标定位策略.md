# 坐标定位策略

## 问题

vision_analyze 看到的图像是缩略图（~1024px），但原始截图可能很大（2K-4K）。
用户说"框住顶部输入框"，你需要精确的像素坐标 `(x, y, w, h)`。

## 四步定位法

### 第一步：获取原图尺寸

```python
from PIL import Image
img = Image.open(path)
w, h = img.size  # 如 2560 x 1440
```

### 第二步：Vision 询问比例坐标

用 vision_analyze 看截图时，问具体位置比例：

> "这张图 2560x1440，顶部输入框在画面的什么位置？请描述大致比例位置"

典型的返回描述：
- "顶部居中，宽度约占画面 60%，高度约占 5%"
- "左侧面板，距左边约 5%，距顶部约 15%"

### 第三步：比例转像素

```
x = 原图宽 × 比例_x      例：2560 × 0.05 = 128
y = 原图高 × 比例_y      例：1440 × 0.15 = 216
w = 原图宽 × 比例_w      例：2560 × 0.60 = 1536
h = 原图高 × 比例_h      例：1440 × 0.05 = 72
```

### 第四步：不确定时让用户确认

当 vision 回报的位置范围较大或模糊时，生成 2-3 个候选坐标方案：

> "我判断要框的位置是以下其中一种，你帮我确认：
>   A) 顶部输入框区域（约 x:0, y:0, w:2560, h:72）
>   B) 底部输入框区域（约 x:0, y:1300, w:2560, h:72）"

## 常见 UI 元素参考比例

| UI 元素 | 常见位置 | 参考比例 |
|---------|---------|---------|
| 顶部导航栏 | 顶部全宽 | x:0, y:0, w:100%, h:5-8% |
| 底部输入框 | 底部居中 | x:5%, y:85%, w:90%, h:8% |
| 左侧面板 | 左侧全高 | x:0, y:0, w:15-25%, h:100% |
| 右侧面板 | 右侧 | x:75%, y:0, w:25%, h:100% |
| 居中弹窗 | 画面中心 | x:15%, y:20%, w:70%, h:60% |
| 按钮 | 各处 | 通常 120-200px 宽, 40-60px 高 |
| 输入框 | 顶部/底部/表单 | 通常 80% 宽, 40-60px 高 |

## 绝对坐标优先

如果 vision 能明确读到元素的具体像素坐标（如"下载按钮在右下角"），优先用绝对坐标而非比例换算。

## 验证

出图后，用 vision 查看 `标注完成/` 下的结果图，确认框的位置正确。
如果偏移明显，调整坐标后重跑。
