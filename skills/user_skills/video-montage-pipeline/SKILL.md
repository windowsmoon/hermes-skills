# 大码女装视频混剪管线

## 核心理念

```
目标（不变）：展示大码女装遮肉显瘦、穿得漂亮
    ↑
主题（热点驱动）：用当下热点话题引流到目标
    ↑
素材 + 文案 + 配音 + 字幕 + 剪映草稿
```

**固定目标：** 大码女装穿搭技巧，遮肉显瘦、穿得漂亮
**可变主题：** 用网络热点作为切入点，比如：

| 热点 | 主题切入点 |
|:----|:-----------|
| 世界杯 | "穿什么去看世界杯？大码女生的球赛穿搭" |
| 换季 | "换季不知道怎么穿？3套大码穿搭拯救你" |
| 高考 | "妈妈穿什么去接考？让孩子出来倍有面子" |
| 七夕 | "约会穿什么？微胖女生显瘦约会穿搭" |
| 春节 | "过年串门怎么穿？大码女生显瘦拜年装" |
| 降温 | "降温了！微胖女生这么穿又暖又显瘦" |

## 完整流程

```
用户说"做视频"
    ↓
Phase 0: 抓热点 + 生成主题
  ├─ TrendRadar / get-the-news 抓当前热点
  ├─ LLM 分析：哪个热点能跟大码女装穿搭结合
  ├─ LLM 生成主题切入点（"穿什么去看世界杯？"）
  └─ 问用户确认主题
    ↓
Phase 1: 素材分析
  ├─ Whisper 转录每个片段
  ├─ vision_analyze 看画面
  └─ LLM 生成素材索引目录
    ↓
Phase 2: 智能选片 + 编排
  ├─ LLM 根据主题选片段
  ├─ LLM 确定片段顺序
  └─ 输出编排方案
    ↓
Phase 3: 旁白文案 + TTS 配音
  ├─ LLM 写旁白文案（热点切入+卖点）
  ├─ Edge-TTS 转语音
  └─ 生成 SRT 字幕
    ↓
Phase 4: 生成剪映草稿（根据模式路由）
  ├─ 简单混剪 → jianying-editor-skill 自然语言驱动
  ├─ 全面混剪 → pyJianYingDraft 精细控制
  └─ 花费混剪 → NemoVideo（需付费套餐）
    ↓
Phase 5: 用户打开剪映导出
  └─ 打开剪映 → 找到草稿 → 加SVIP美颜 → 导出MP4
```

## 触发步骤

### 第一步：用户说"做视频"

**1. 先抓热点**
> 我先看看今天有什么热点可以蹭...

然后输出 3-5 个热点+主题切入点给用户选

**2. 用户确定主题**

**3. 素材在哪？**
> 你把素材放在哪个文件夹？

**4. 选什么模式？**
> ① 简单混剪 — 快速出片
> ② 全面混剪 — 精细控制，美颜/特效/转场全开
> ③ 花费混剪 — NemoVideo（需付费）
