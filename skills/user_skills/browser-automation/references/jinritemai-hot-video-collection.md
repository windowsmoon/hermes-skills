## browser_text 输出结构 & 正确解析方法

`browser_text(maxLength=20000)` 返回全页面文本。**按 `"总播放量"` label 分割**，不要按固定行号切分（侧边栏浮动UI会干扰行号）。

### 分割结构

```
splits[0] (第一段): 视频1元数据（前5行）
  [0] 视频1标题标签（#开头）
  [1] 视频1博主名
  [2] 视频1发布时间
  [3] 视频1时长
  [4] 视频1摘要（商品描述）

splits[1]: 视频1数据（前9行）+ 视频2元数据（后5行）
  [0:9] 视频1数据: 
    [0] 播量数字, [1] 万+, [2] 新播量数字, [3] 万+,
    [4] "已选类目结算金额"（label）
    [5] 金额, [6] "总点赞量"（label）, [7] 点赞数字, [8] +
  [-5:] 视频2元数据: 同上格式（标题标签/作者/时间/时长/摘要）

splits[2..4]: 同上结构（各视频数据+下一视频元数据）
splits[5]: 视频5数据（9行，无后续元数据）
```

### 正确 Python 解析代码

```python
import csv

raw = """<browser_text 返回的原始文本>"""

splits = raw.split('总播放量')
# splits[0] = 视频1元数据（前5行）
# splits[1..4] = 视频数据(前9行) + 下一视频元数据(后5行)
# splits[5] = 视频5数据（9行，无后续）

def make_video(meta, data):
    return {
        '视频标题与标签':   meta[0],
        '博主名称':         meta[1],
        '发布时间':         meta[2],
        '视频时长':         meta[3],
        '视频摘要':         meta[4],
        '总播放量':         data[0] + data[1],
        '新增播放量':       data[2] + data[3],
        '已选类目结算金额': data[5],
        '总点赞量':         data[7] + data[8],
    }

videos = []
# 视频1
meta1 = splits[0].strip().split('\n')
data1 = splits[1].strip().split('\n')[:9]
videos.append(make_video(meta1, data1))

# 视频2-5
for i in range(1, 5):
    sec = splits[i].strip().split('\n')
    data_part = sec[:9]
    meta_part = sec[-5:]
    videos.append(make_video(meta_part, data_part))

# 保存 CSV
out = "C:/Users/Admin/Desktop/jinritemai_hot_videos.csv"
with open(out, 'w', newline='', encoding='utf-8-sig') as f:
    w = csv.DictWriter(f, fieldnames=[
        '视频标题与标签','博主名称','发布时间','视频时长',
        '视频摘要','总播放量','新增播放量','已选类目结算金额','总点赞量'
    ])
    w.writeheader()
    w.writerows(videos)
```

## 技术限制 & 应对

| 问题 | 原因 | 解法 |
|------|------|------|
| `browser_evaluate` 返回空 | real-browser-mcp 安全沙箱限制 | **用 `browser_text` 替代**，可正常提取 |
| API 无法直调（返回10001010A） | `msToken`/`a_bogus` 为动态签名，Cookie绑定 | 只能在活着的浏览器 Session 中调用，或让用户手动导出 |
| `ClosedResourceError` | MCP 服务断开 | `browser_navigate` 刷新页面 → 还不行则开新 Session |
| 解析错位（出现"总播放量"、"已选类目结算金额"出现在作者/时间字段） | 按固定行号切分，被浮动UI干扰 | 按 `"总播放量"` label 动态分割 |
