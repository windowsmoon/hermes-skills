
### 1.2 架构原则

| 原则 | 说明 |
|------|------|
| **事件驱动** | 所有环节通过消息队列衔接，解耦消费速率 |
| **幂等设计** | 每条消息携带全局唯一 ID，下游消费端支持去重重入 |
| **失败隔离** | 每个服务独立进程/容器，失败不阻塞上下游 |
| **可观测** | 全链路 Trace ID 透传，结构化日志 + 状态记录 |
