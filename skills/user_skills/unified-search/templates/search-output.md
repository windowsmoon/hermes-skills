# 搜索结果输出模板

Agent 向用户呈现搜索结果时，严格按照以下格式。

## 输出结构

```
═══ 统一搜索结果：「<搜索词>」 ═══

🔥 推荐优先阅读
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

① <文章标题>
📝 <正文摘要 200-400 字，从原文抓取>
🔗 <完整可点击 URL>

② ...

📚 补充参考
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
③ ...（同上格式）

📁 本地笔记
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
<命中结果 / 注明"未命中">

🧠 历史讨论
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
<相关会话 / "无">

📊 来源状态
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• Tavily:    ✅ N条（剩余约 XXX/1000）
• Exa:       ✅ N条（⚠️ 需补抓正文）
• 秘塔:       ✅ N条（剩余 X credits）
• Firecrawl: ⚠️/🔴 说明原因
• Obsidian:  ⚪ 未命中
```

## 规则

1. **每条必须有 🔗 URL** — 无 URL=不完整
2. **每条必须有 📝 摘要** — 从原文抓取前 200-400 字
3. **摘要抓取失败** — 注明原因（反爬/超时/403），不留白
4. **空结果** — 解释原因，不写"无结果"
5. **来源状态** — 每个源用 ✅/⚠️/🔴/⚪ 标注
6. **推荐排序** — 用 🔥 / 📖 / 📎 标记优先级
