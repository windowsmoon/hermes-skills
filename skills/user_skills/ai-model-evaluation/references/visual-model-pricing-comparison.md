## 能力对比

### Qwen3-VL-Plus 优势
- 原生支持长视频理解（几小时），能精准定位"某句话在几分几秒"
- 32项核心能力评测超过 Gemini 2.5 Pro 和 GPT-5
- 支持思考模式 + 非思考模式融合
- 视觉 Coding、空间感知、多模态思考全面升级
- 上下文 262K tokens

### Doubao-Seed-1.6-Vision 优势
- VisualCoT（视觉链式思考）— 自动 zoom 放大细节，逐步推理
- 短输入（< 32K）时价格只有 Qwen3-VL-Plus 的不到一半
- 适合短视频分析、图片细节识别、GUI Agent
- 缓存命中可大幅降低成本

### 评测来源
- 火山引擎官方 18 个案例实测
- 知乎/CSDN 第三方评测
- EvalScope 评测最佳实践

## 性价比建议
- **短视频/录屏分析（输入 < 32K）**：Doubao-Seed-1.6-Vision 性价比碾压
- **长视频深度分析**：Qwen3-VL-Plus 效果更好，原生支持长视频
- **Agent/编程类视觉任务**：Doubao-Seed-2.1 Pro 在 OSWorld 多模态评测强但贵 5 倍
