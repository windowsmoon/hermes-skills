# 巨量百应爆款视频页 DOM 结构记录

## 页面URL
```
https://buyin.jinritemai.com/dashboard/inspiration-center/hot-video
```

## 筛选区域
位于页面顶部，可通过URL参数或页面元素操作设置：
- 行业类目（服装/家居日用/食品饮料/美妆/生鲜...）
- 视频时长（不限/15秒内/1分钟内/大于1分钟）
- 作者等级（Lv0-Lv7）
- 排序方式（新增结算金额/新增播放量）

## 列表区域
页面主体为无限滚动列表，每条视频卡片包含：

```
┌─────────────────────────────────────────────────┐
│  👤 博主名称                                      │
│  🕐 发布时间  |  ⏱ 视频时长                       │
│                                                   │
│  📝 视频标题+话题标签                              │
│  📦 商品摘要/商品名称                             │
│                                                   │
│  总播放量 100万+    新增播放量 100万+              │
│  已选类目结算金额 10万-50万                        │
│  总点赞量 2000+                                   │
└─────────────────────────────────────────────────┘
```

## 文本提取结构（已验证）
通过 tabbit_extract(type="text") 提取的文本格式：

```
[视频标题+话题标签]
[博主名称]
[发布时间 yyyy/MM/dd HH:mm:ss]
[视频时长 N分N秒 / N秒]
[商品摘要/商品名称]
总播放量
[数字]
万+
[数字]
万+
已选类目结算金额
[金额]
总点赞量
[数字]
+
```

每条视频共19行（5行元数据 + 9行数据 + 标记行）。

## 数据分割标记
- `"总播放量"` — 每个视频块的分割点
- split[0] = 视频1的元数据（前5行）
- split[1..N] = 前9行是数据，后5行是下一视频的元数据
- split[last] = 最后一条视频的数据（9行）

## 注意事项
1. 页面使用无限滚动（intersection observer），需要滚动触发加载
2. 每次滚动约加载 5 条新视频
3. 滚动到底部会显示"没有更多内容"
4. 页面有强反爬检测，必须使用 antidetect
5. 登录态会过期（约24小时），过期后跳转到登录页
6. Cookie 可通过 tabbit_cookies 持久化
