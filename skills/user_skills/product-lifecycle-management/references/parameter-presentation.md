# 参数呈现原则（用户偏好）

> 用户明确反馈："你要把选项给我中文翻译过来的选项名称啊，不然我完全不知道可以回答什么，我不想做填充题"

## 核心原则

所有需要用户选择参数/选项的场景，必须按选择题格式呈现，**不得让用户做填空题**。

## 标准格式

```
### ① 分类名称
> 问题描述？
  1. 🔵 选项A（简要说明）
  2. 🟣 选项B（简要说明）
  3. ⚪ 选项C（简要说明）
  4. 🔢 自定义（你说我调）
```

## 规则

1. 每个选项必须有 **Emoji 前缀 + 中文名称 + 括号说明**
2. 必须包含「自定义」或「默认」选项
3. 用户只需回复**数字**即可选择
4. 用户说"默认"或"自动" → 直接使用智能推荐值跳过该参数
5. 超过 5 个选项时分组呈现，每组不超过 5 个

## 正确示例

```
### ① 配色风格
> 选哪种整体配色？
  1. 🔵 科技蓝（深蓝+青绿）
  2. 🟣 赛博朋克（霓虹粉+青蓝）
  3. ⚪ 极简白（白+灰+点缀红）
  4. 🎨 自定义（你说我调）
```

## 错误示例（禁止）

```
请输入配色方案：_________
请告诉我你想要的字体：_________
页数是多少？_________
```

## 适用范围

所有用户交互 skill，包括但不限于：
- 产品生命周期各步骤的参数选择
- PPT 生成的风格/字体/布局参数
- 任务编排的选项配置
- 文档解析的参数配置
