# 用户偏好：参数呈现方式

## 核心规则

当需要用户做选择时，**必须**呈现为编号选择题，**禁止**开放填空式提问。

## 正确格式示例

```
> 配色风格选哪个？
  1. 🔵 科技蓝（深蓝+青绿）
  2. 🟣 赛博朋克（霓虹粉+青蓝）
  3. ⚪ 极简白（白+灰+点缀红）
  4. 🟠 暖色调（深色底+橙金）
  5. 🌈 渐变风（紫蓝渐变）
  6. 🎨 自定义（你说我调）
  7. 默认（自动匹配）
```

## 格式要求

1. **每行一个选项**：数字编号 + emoji + 名称 + （括号补充说明）
2. **emoji** 帮助快速视觉区分，必须每个选项配一个
3. **括号说明**帮助理解差异，控制在 10 字以内
4. **最后一个选项必须是"默认/自动"**，让用户可以跳过
5. 如果用户说"默认"或"自动"，直接用默认值，不追问

## 反例（禁止使用）

```
❌ 你想要什么颜色？
❌ 请输入配色方案：
❌ 选择字体：（用户需要自己打字输入）
❌ 选哪个模板？（无选项）
```

## 适用场景

- 任何需要用户配置参数的步骤
- 工作流配置
- 风格/主题选择
- 报告格式选择
