# 用户交互参数选择规范

## 核心原则

当需要用户做选择时，**必须**呈现为编号选择题，**禁止**开放填空式提问。

## 正确格式

```
> 问题描述？
  1. 🔵 选项一（简短说明）
  2. 🟣 选项二（简短说明）
  3. ⚪ 选项三
  7. 默认/自动（可跳过）
```

## 格式要求

1. **每行一个选项**，数字编号 + emoji + 名称 + （括号补充说明）
2. **emoji** 帮助快速视觉区分，必须每个选项配一个
3. **括号说明**帮助理解差异，控制在 10 字以内
4. **最后一个选项必须是"默认/自动"**，让用户可以跳过
5. **不支持"其他（请填写）"**——如果用户需要自定义，单独设计"自定义"选项

## 反例（禁止使用）

```
❌ 你想要什么颜色？
❌ 请输入配色方案：
❌ 选择字体：（用户需要自己打字输入）
```

## 适用场景

- 任何需要用户配置参数的步骤
- PPT 生成参数调查
- 工作流配置
- 风格/主题选择
- 报告格式选择
