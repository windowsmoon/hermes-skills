# 用户偏好的优化→确认→迭代→执行流程

## 完整工作流（用户确认）

1. **用户说** `帮我优化提示词：XXX`
2. **Agent** 运行 `prompt_optimizer.py user "..."` → 展示**原始完整输出**（不改写不概括）
3. **用户审查** 原始输出，给出修改意见（"第二段再细化一下"）
4. **Agent** 运行 `prompt_optimizer.py iterate "..."` → 基于反馈输出新版本
5. **用户确认**（"好了，执行吧"）→ Agent 使用最终版本执行任务

## 关键原则

- 每次展示都必须包含 **原始输出**，不是 agent 的概括
- 迭代只根据用户指出的方向调整，不要擅自扩写
- 用户没说"好了"之前，不要最终执行
