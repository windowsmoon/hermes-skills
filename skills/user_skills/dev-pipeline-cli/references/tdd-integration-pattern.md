# TDD 集成模式：原则层 + 执行层

## 两层级联架构

本用户的 TDD 开发规范通过两层联动生效，缺一不可：

```
┌─────────────────────────────────────┐
│  层1：原则层（SOUL.md）               │
│  研发总监 Profile · 第7条规则          │
│  "在提示词中明确要求 AI 遵循 TDD 流程"  │
│  → 定义"做什么"                       │
├─────────────────────────────────────┤
│  层2：执行层（SKILL.md）               │
│  dev-pipeline-cli · 6步工作流         │
│  第2步：先写测试用例                    │
│  第3步：调 OpenCode CLI 写实现代码      │
│  第4步：测试验证                       │
│  → 定义"怎么做"                       │
└─────────────────────────────────────┘
```

## 原则层（SOUL.md）负责什么

- 声明岗位规范和行为准则
- 定调（"必须用 TDD"）
- 不涉及具体操作步骤
- 被其他 Profile/Agent 引用时只读

## 执行层（Pipeline）负责什么

- 具体工作流的编排和步骤定义
- 提示词模板的注入
- 任务的拆分和验证
- 可被其他 Skill 调用和复用
